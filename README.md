# JANA

JANA is the JLab ANAlysis framework. It is a multi-threaded C++ framework for processing event-based data from particle physics experiments. It has been primarily used by the GlueX experiment at Jefferson Lab.


**This project has been superseded by [JANA2](https://github.com/JeffersonLab/JANA2)**. JANA2 is the modern, high-performance successor to the JANA framework, developed at Jefferson Lab. It is a multi-threaded, C++ streaming and event-processing framework specifically designed for data processing for nuclear and particle physics analyses. JANA2 is used by large-scale experiments such as [Electron Ion Collider ePIC](https://www.bnl.gov/eic/epic.php), [GlueX](https://en.wikipedia.org/wiki/GlueX], multiple Jefferson Lab experiments [1](https://www.epj-conferences.org/articles/epjconf/pdf/2021/05/epjconf_chep2021_04011.pdf), [2](https://www.jlab.org/exp_prog//proposals/14/PR12-14-010.pdf) and research projects [3](https://www.osti.gov/biblio/2324811)[4](https://github.com/JeffersonLab/JANA4ML4FPGA). Please, follow [JANA2](https://github.com/JeffersonLab/JANA2) page.
