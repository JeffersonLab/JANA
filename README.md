# JANA

JANA is the JLab ANAlysis framework. It is a multi-threaded C++ framework for processing event-based data from particle physics experiments. It has been primarily used by the GlueX experiment at Jefferson Lab.

**This project has been superseded by [JANA2](https://github.com/JeffersonLab/JANA2).**

JANA2 is the modern, high-performance successor to the JANA framework developed at Jefferson Lab. It is a multi-threaded C++ framework optimized for streaming and event-based data processing in nuclear and particle-physics analyses. JANA2 is already used by large-scale experiments such as the [Electron–Ion Collider ePIC](https://www.bnl.gov/eic/epic.php) and [GlueX](https://en.wikipedia.org/wiki/GlueX), as well as by several Jefferson Lab experiments [1](https://www.epj-conferences.org/articles/epjconf/pdf/2021/05/epjconf_chep2021_04011.pdf), [2](https://www.jlab.org/exp_prog//proposals/14/PR12-14-010.pdf) and research projects [3](https://www.osti.gov/biblio/2324811), [4](https://github.com/JeffersonLab/JANA4ML4FPGA).

Please visit the [JANA2 repository](https://github.com/JeffersonLab/JANA2) for the latest code and documentation.
